# Backlog de Mejoras e Ideas

Documento para anotar ideas de mejora que surjan durante el desarrollo o las pruebas — cosas que **no son bugs** (la app funciona como se especificó) pero que podrían hacerla mejor, y que **no forman parte del alcance ya cerrado** en `proyecto-padel-qa-alcance.md` (ese alcance no se modifica acá; esto es insumo para futuras iteraciones o para revisar el roadmap de fases).

Sirve también para no perder ideas que aparecen "al pasar" mientras se prueba otra cosa, sin interrumpir el trabajo en curso para decidir si se hacen o no.

## Convenciones

- **ID:** `MEJ-XXX` correlativo. Como este documento lo puede editar cualquier chat del Proyecto, releelo primero para tomar el próximo número libre de una versión fresca — no asumas que el último ID que viste sigue siendo el más alto, otro chat puede haber cargado una idea mientras tanto.
- **Origen:** épica/feature desde la que surgió la idea (o "General" si aplica a toda la app).
- **Estado:** Propuesta → En evaluación → Aceptada (se suma a una fase futura) / Descartada (se decide no hacerla, con motivo) → Implementada.
