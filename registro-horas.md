# Registro de horas — App Padel

> **Qué es este documento:** un registro simple de las horas que el usuario le dedicó al proyecto, sesión por sesión. **Importante — limitación real:** ningún chat de Claude puede medir el tiempo transcurrido de forma confiable (no hay reloj propio ni continuidad entre mensajes), así que este registro depende 100% de que el usuario indique cuánto tiempo trabajó (por ejemplo "empecé a las 9, son las 14" o "trabajé 3 horas") — ningún chat debe inventar ni estimar una cifra por su cuenta. Cualquier chat del Proyecto puede sumar una fila acá cuando el usuario avise que cierra una sesión de trabajo (o que ya la cerró y quiere dejarlo anotado).

## Cómo se agrega una fila

1. El usuario dice cuánto tiempo trabajó (hora de inicio y fin, o directamente la cantidad de horas).
2. El chat activo en ese momento agrega una fila acá con la fecha, el chat, las horas y una nota si hace falta aclarar algo (ej. si el tiempo incluyó trabajo en más de un chat del Proyecto).
3. Se actualiza el total acumulado al final del documento.
4. Se replica este documento en la carpeta local del usuario, igual que cualquier otro documento del Proyecto.
